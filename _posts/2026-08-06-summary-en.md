## [LLM 0.32 adds reasoning traces, server-side tools, and OpenAI Responses support](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

Version 0.32 of the LLM CLI was released, introducing visible reasoning traces printed to stderr, built‑in support for the GPT‑5.6 model family (defaulting to the inexpensive GPT‑5.6 Luna), and server‑side provider tools such as OpenAI's CodeInterpreter and WebSearch. It also adds a new "llm openai endpoint" command for one‑off prompts to any OpenAI‑compatible endpoint and updates the llm‑anthropic plugin with WebSearch, WebFetch, CodeExecution, and AnthropicMCP capabilities. Reasoning traces let developers see how a model arrives at its answer, making debugging and prompt engineering far more transparent. Server‑side tools and the OpenAI Responses API enable richer, agentic workflows directly from the CLI without writing custom integration code, expanding the practical utility of LLMs for a wide range of developers. Reasoning traces are sent to standard error and can be suppressed with the -R/--hide-reasoning flag; logs are now stored in a content‑addressable SQLite database. Server‑side tools only work with providers that expose them, and the new openai endpoint command deliberately avoids logging prompts for privacy. The default model switch to GPT‑5.6 Luna reduces cost while maintaining capability.

rss · Simon Willison · Aug 4, 23:58

**Background**: The LLM CLI is a command‑line interface for interacting with large language models, allowing users to send prompts and receive completions from various providers. A reasoning trace is a step‑by‑step log of the model's internal chain‑of‑thought, useful for debugging and understanding model behavior. Server‑side provider tools let the model invoke external services (e.g., code execution, web search) on the provider's infrastructure, simplifying agentic patterns. The OpenAI Responses API combines chat completions and assistant features into a single endpoint, streamlining integration for developers.
