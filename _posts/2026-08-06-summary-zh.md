LLM 0.32 版发布，新增在标准错误输出的可见推理追踪、对 GPT‑5.6 系列模型（默认使用性价比高的 GPT‑5.6 Luna）的内置支持，以及 OpenAI CodeInterpreter 与 WebSearch 等服务器端工具。还加入了 "llm openai endpoint" 命令，可对任意兼容 OpenAI 的端点执行一次性提示，并对 llm‑anthropic 插件进行了大幅升级，加入 WebSearch、WebFetch、CodeExecution 与 AnthropicMCP 功能。 推理追踪让开发者能够看到模型的思考过程，显著提升调试和提示工程的可视化。服务器端工具和 OpenAI Responses API 让 CLI 直接实现更复杂的代理式工作流，无需自行编写集成代码，扩大了 LLM 对各类开发者的实用价值。 推理追踪会输出到标准错误，可通过 -R/--hide-reasoning 参数关闭；日志采用可内容寻址的 SQLite 存储。服务器端工具仅在提供相应支持的供应商可用，新的 openai endpoint 命令不会记录提示以保护隐私。默认模型改为 GPT‑5.6 Luna，降低成本且保持性能。

rss · Simon Willison · 8月4日 23:58

**背景**: LLM CLI 是用于与大型语言模型交互的命令行工具，用户可以向不同提供商发送提示并获取回复。推理追踪是模型内部思考链的逐步日志，有助于调试和理解模型行为。服务器端提供商工具使模型能够在提供商的基础设施上调用外部服务（如代码执行、网络搜索），简化了代理式模式。OpenAI Responses API 将聊天完成和助理功能合并为单一接口，便于开发者统一集成。
